# Fechos de Cobrança 20–20

Esta pasta guarda os fechos preparados para enviar ao patrão, um por ciclo do dia 20 ao dia 20.

Use [[Templates/Ação - Fecho de Cobrança 20-20]] para criar um fecho. Reveja sempre quantidades, unidades, valores e evidências antes de enviar a mensagem por WhatsApp ou e-mail.

O sistema prepara o texto, mas **não envia mensagens automaticamente**.
