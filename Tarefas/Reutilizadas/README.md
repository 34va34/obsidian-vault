# Tarefas Reutilizadas

Esta pasta recebe as tarefas criadas pela ação [[Templates/Ação - Repetir Trabalhos]].

Cada nota representa uma aplicação concreta de um trabalho-modelo a uma obra, lote ou piso. Não apagar o campo `trabalho_id`: é ele que mantém a ligação ao catálogo e às vistorias.
